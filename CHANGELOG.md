# Changelog

## 0.5.0 - 2026-09-10

- Added local repository scanning with portable ignore handling.
- Added common secret detection, including GitHub, AWS, npm, Google, JWT, and private-key shapes.
- Added Markdown and JSON context pack generation with token budgets.
- Added include/exclude filters, max-file-size controls, and `reposieve init`.
- Added CI-friendly `check` command and configuration via `.reposieve.toml`.
- Added free/Pro product boundary documentation.
